# 3 Sœurs — Claude Site Guide

This is a static HTML site. Claude acts as the build system. Source files live in `_source/`. Output HTML files are generated by Claude from those sources and must never be edited by hand.

---

## Quick Reference

| Task | Action |
|---|---|
| Edit page content | Modify `_source/pages/[page].html`, regenerate its output file |
| Edit layout / head / footer | Modify `_source/_layout.html`, regenerate ALL 11 output files |
| Add a new page | Create `_source/pages/[slug].html`, create output dir, generate output |
| Add a new library | Copy `_source/pages/1.html` as template, update all fields, add page-card to home page source |

## How to Generate a Page

1. Read `_source/_layout.html`
2. Read `_source/pages/[page].html`
3. Parse the frontmatter block (HTML comment at top of file)
4. Extract any special blocks from the page file (see below)
5. Pick a random `{{STROKE_HUE}}` from `[0, 36, 72, 108, 144, 180, 216, 252, 288, 324]` (as `Ndeg`)
6. Expand all shorthand tags in the content (see Shorthand Tags below)
7. Calculate `{{FOOTER_THEME}}` from the section count
8. Fill in all `{{PLACEHOLDER}}` values in the layout
9. Write the result to the `output` path in the frontmatter

### Placeholders

| Placeholder | Value |
|---|---|
| `{{TITLE}}` | `title` frontmatter |
| `{{DESCRIPTION}}` | `description` frontmatter |
| `{{OG_TITLE}}` | `og-title` frontmatter, falls back to `title` |
| `{{OG_DESCRIPTION}}` | `og-description` frontmatter, falls back to `description` |
| `{{OG_IMAGE}}` | `og-image` frontmatter |
| `{{OG_URL}}` | `og-url` frontmatter |
| `{{FAVICON_JPG}}` | `favicon-jpg` frontmatter, defaults to `/share.jpg` |
| `{{PREFIX}}` | `""` depth 0 · `"../"` depth 1 · `"../../"` depth 2 |
| `{{STROKE_HUE}}` | Random hue picked at generation time, e.g. `144deg` |
| `{{HEADER}}` | Full header HTML (see below) if `no-header` is absent; empty if `no-header: true` |
| `{{FOOTER_THEME}}` | `dark` if section count is even; `light` if odd |
| `{{EXTRA_HEAD}}` | Contents of `<!-- EXTRA_HEAD -->...<!-- /EXTRA_HEAD -->` in page file, or empty |
| `{{BEFORE_SHELL}}` | Contents of `<!-- BEFORE_SHELL -->...<!-- /BEFORE_SHELL -->` in page file, or empty |
| `{{CONTENT}}` | All shorthand-expanded HTML below the frontmatter/special blocks |
| `{{EXTRA_SCRIPTS}}` | Contents of `<!-- EXTRA_SCRIPTS -->...<!-- /EXTRA_SCRIPTS -->` in page file, plus any scripts auto-generated from shorthand expansion (e.g. `<project-contact>`) |

When a placeholder resolves to empty, omit any surrounding blank lines in the output.

### Header HTML

When `no-header` is absent, `{{HEADER}}` expands to:

```html
    <header class="site-header">
      <a href="/"><h1><span class="number">3</span>sœurs</h1></a>
    </header>
```

## Shorthand Tags

Source files use shorthand tags as a notation. During generation, Claude replaces each with pure HTML. No web components or JS are emitted in the output.

### `<page-section [id="X"]>`

```html
<section class="page-section"[ id="X"]>
  <div class="page-section-inner">
    [content]
  </div>
</section>
```

Sections alternate dark/light via CSS `nth-of-type`. First section is always dark.

### `<page-poster image="./foo.jpg">`

```html
<div class="page-poster"><img src="./foo.jpg" alt="" /></div>
```

### `<page-card href="H" image="I" title="T" description="D" cta="C" [subtitle="S"]>`

```html
<div class="page-card">
  <a href="H">
    <div class="img"><img src="I" alt="T" /></div>
  </a>
  <h4>T</h4>
  [<h5>S</h5>]
  <p>D</p>
  <a class="cta" href="H" style="--btn-hue: Xdeg">C »</a>
</div>
```

Pick `Xdeg` from the hues array at generation time.

### `<project-contact project-id="N">`

Expands to form HTML in `{{CONTENT}}`:

```html
<h2 id="memory-heading">What should this library remember?</h2>
<p id="memory-intro">Leave a note or share a memory. We'd love to know what this library means to you.</p>
<form id="memory-form">
  <input type="text" name="name" placeholder="Name (optional)" />
  <textarea rows="4" name="message" placeholder="What you're thinking about" required></textarea>
  <button type="submit" style="--btn-hue: Xdeg">Leave your mark</button>
</form>
```

Also auto-generates and appends to `{{EXTRA_HEAD}}`:

```html
<script src="https://cdn.jsdelivr.net/npm/@emailjs/browser@4/dist/email.min.js"></script>
```

And auto-generates and appends to `{{EXTRA_SCRIPTS}}`:

```html
<script>
  emailjs.init({ publicKey: "bj2L_S3nwdlIeg191" });
  const form = document.getElementById("memory-form");
  const heading = document.getElementById("memory-heading");
  const intro = document.getElementById("memory-intro");
  form.querySelector("textarea").addEventListener("invalid", function () {
    this.setCustomValidity("Tell us a little something.");
  });
  form.querySelector("textarea").addEventListener("input", function () {
    this.setCustomValidity("");
  });
  form.addEventListener("submit", function (e) {
    e.preventDefault();
    const btn = form.querySelector("button");
    btn.disabled = true;
    btn.textContent = "Sending...";
    emailjs.send("3Soeurs", "template_61eezn8", {
      project_id: "N",
      email: form.querySelector('[name="name"]').value || "Anonymous",
      message: form.querySelector('[name="message"]').value,
    }).then(
      function () {
        form.style.display = "none";
        intro.style.display = "none";
        heading.textContent = "Remembered. Thank you.";
      },
      function () {
        btn.disabled = false;
        btn.textContent = "Leave your mark";
      }
    );
  });
</script>
```

### `<a class="btn">` and `<button>` elements

Add `style="--btn-hue: Xdeg"` to each, picking `Xdeg` from the hues array at generation time.

Source structure:
```

  <h2>[Title]</h2>
  <p>Trois Sœurs is Jane, Ruby, and Lucy. [opening paragraph]</p>

  <project-contact project-id="N"></project-contact>

[additional page-poster images]
```

The "Trois Sœurs is Jane, Ruby, and Lucy…" paragraph appears on every library page. Keep it.
Section count: 2 → footer is **dark**.


### Home Page — depth 0 (`index.html`)

Special. Uses `EXTRA_HEAD` for hero styles + emailjs CDN, `BEFORE_SHELL` for the hero video div, `no-header: true`, and `EXTRA_SCRIPTS` for the contact form handler.

The contact section has `id="contact"`, its form has `id="contact-form"` — the EXTRA_SCRIPTS block depends on these IDs.

Section count: 4 → footer is **dark**.

## Style Rules

1. **Never hardcode colors** — always use CSS variables.
2. **Image paths are relative** from the output file's directory (`./poster.jpg`, not `/1/poster.jpg`).
3. **Section order drives dark/light** — `section.page-section:nth-of-type(odd)` is dark, even is light. Order matters visually.
4. **Footer theme** is determined at generation time from section count (odd → light, even → dark).
5. **OG image**: library pages use their own `/N/share.jpg`; all other pages use `/share.jpg`.
6. **Favicon JPG**: library 1 uses `./share.jpg` (has a unique share image); all others use `/share.jpg`.
7. **Hues are baked in** at generation time via inline `style` attributes. Never use JS to set hues.
8. **Analytics** is included in the layout template. Do not add GA scripts to individual pages.
